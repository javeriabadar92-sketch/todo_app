# 📝 State-Managed Todo App

A beautiful, modern, and production-ready Task Management application built using Flutter. This project showcases clean architecture, local data handling, and smooth user interactions designed to boost daily productivity.

## 🚀 Key Features
* **Task Management:** Seamlessly create, read, update, and delete (CRUD) tasks.
* **Status Toggles:** Mark tasks as completed or active with interactive checkboxes.
* **Modern UI/UX:** Features sleek animations, clean layout spacing, and a responsive interface.
* **State Isolation:** Keeps business logic clean and detached from the UI widgets.

## ⚙️ Setup & Installation

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd todo_app
   ```
3. **Install dependencies:**
   ```bash
   flutter pub get
   ```
4. **Launch the application:**
   ```bash
   flutter run
   ```
